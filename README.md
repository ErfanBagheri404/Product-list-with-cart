# Product list with cart

![Design preview for the Product list with cart challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Product list with cart** challenge - a responsive app built from the provided design.

**Live demo:** https://erfan-revenant.github.io/Product-list-with-cart/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Vanilla JavaScript for the interactive behaviour (no framework, no build step)
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Product-list-with-cart.git
cd Product-list-with-cart
```

Open `index.html` in a browser. Nothing to install or compile.
